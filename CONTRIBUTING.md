# Contributing

Fountain Ink Engine is experimental. Open a focused change that modifies one
material hypothesis or one library concern at a time.

1. Read `AGENTS.md`, `docs/CURRENT.md`, and `docs/EXPERIMENT_LOG.md`.
2. Keep UI, product, storage, platform, and private-service code outside this repo.
3. Supply explicit seeds and version any changed calculation or recipe shape.
4. Record both successful and failed material experiments.
5. Run `npm run verify` and `npm pack --dry-run`.

Do not submit fonts, screenshots, or sample media without redistribution rights
and a matching entry in `THIRD_PARTY_NOTICES.md`.
