# Security policy

## Supported versions

This project is pre-1.0 and currently supports only the latest published
experimental release.

## Reporting

Please report a vulnerability privately through GitHub's security-advisory
feature for the public repository. Do not include secrets, private product code,
or personal writing samples in a public issue.

This library performs local deterministic calculation and should not add network,
credential, telemetry, or dynamic-code execution behavior without an explicit
security review.
