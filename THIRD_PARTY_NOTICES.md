# Third-party notices

The published `fountain-ink-engine` package currently bundles no third-party
runtime code, font, screenshot, reference image, or media asset.

Fonts are caller-provided inputs to browser text shaping. The current HTML
comparison harness uses Nanum Pen Script under its own dependency and license;
that font is not part of this library package. A future bundled font or asset
must add its license and attribution here before publication.
